# HorseManWingsApp
Horse Man Wings is an iOS application built with Swift and UIKit for a real farm. The app allows visitors to explore the farm, learn about its animals, book services, purchase farm products, and manage their personal account.

## Features

- 🏡 Farm information and history
- 📍 Farm location and reviews
- 🐴 Animal catalog with detailed profiles
- 🚜 Farm services and horseback riding
- 🥩 Meat and egg product catalog
- 🛒 Order creation and payment
- 👤 User profile and order history
- 🔔 Order reminders
- 🏆 Loyalty system with ranks and discounts

## Technologies

- Swift
- UIKit
- Auto Layout
- UITableView
- UICollectionView
- MVC
